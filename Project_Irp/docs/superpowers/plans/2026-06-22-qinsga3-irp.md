# QINSGA-III for MPIRP — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or
> superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add a `QINSGA3/` module that solves the 4-objective MPIRP using a
Quantum-Inspired NSGA-III, reusing the existing decoder, evaluator, and report
pipeline from `NSGA3/`.

**Architecture:**  
Chromosome = angle vector θ ∈ [0, π/2]^n. Measurement maps θ → real decision
variables via `x_j = xl_j + cos²(θ_j) × (xu_j - xl_j)`, feeding the existing
`build_routes` decoder unchanged. NSGA-III non-domination ranking selects Pareto
guides; each chromosome rotates toward its guide with adaptive step α(gen).

**Tech Stack:** Python 3.11, numpy, pymoo 0.6.x (NonDominatedSorting utility),
reuses NSGA3.problem.IRPProblem, NSGA3.decoder, NSGA3.evaluator, NSGA3.report.

## Global Constraints

- No new decoder or repair function — `NSGA3.decoder.build_routes` handles all
  constraint satisfaction already (capacity, stock, deadlines).
- Report format must be identical to `NSGA3/` so `NSGA3/report.py` is reused.
- pop_size default = 200, n_gen default = 200, N_PARTITIONS = 8 (same as NSGA3).
- α_max = 0.05π, α_min = 0.001π (Platel et al. 2007 empirical range).
- Per-gene mutation probability = 1/n_genes (same convention as NSGA-III PM).
